Whe using the VIM editor,

1. Press Esc
2. Press `i` (insert)
   1. Type messages in the git bash text editor
3. Press `:`
4. Enter any of the following:
   - `x!` - Exit without saving changes
   - `x`
   - `wq!` - Save and exit
5. Press Enter
