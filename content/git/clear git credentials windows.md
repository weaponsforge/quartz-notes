## Methods

1. Search for **Credential Manager** in the search panel.
2. Click the **Windows Credentials** when inside  the Credential Manager window.
3. Go under **Generic Credentials**.
4. Delete Git-related credentials.
5. Clone a repository and enter valid credentials when prompted.
