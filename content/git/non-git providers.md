### Steps

1. Create an account on Ubuntu One [link](https://login.ubuntu.com/)
2. Register and sign-in at [review.opendev.org](https://docs.opendev.org/opendev/infra-manual/latest/gettingstarted.html)
3. Clone, push and pull
