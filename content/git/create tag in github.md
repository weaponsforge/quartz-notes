1. Go to your project's main page.
2. Click the `Releases` tab.
3. Press the *Draft a New Release* button.
4. In the Draft a New Release page,
   - Tag version: write your tag, i.e., `v.3.0.0`
   - Target: choose a branch
   - Release title: your release title i.e.,
      `dextraction v.3.0.0`
